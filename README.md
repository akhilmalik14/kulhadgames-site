# kulhadgames.com

Static site for Kulhad Games, served by GitHub Pages (custom domain in `CNAME`). No scripts, no cookies, no tracking.

- Edit pages in `src/*.html` (fragments; first lines = title + description), then `python3 build.py` → `<page>/index.html` + `sitemap.xml`.
- Shared look: `assets/site.css` (Baloo 2 + Mukta, self-hosted subsets, SIL OFL — licences in `assets/fonts/`).
- Art comes from the game repo's `Docs/Store` (store art + screenshots, resized to JPEG).
